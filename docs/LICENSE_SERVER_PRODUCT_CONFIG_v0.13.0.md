# Licence Server Product Configuration — Sonkupik Live

The desktop client is configured for the existing MasArray licence API and Midtrans flow.

The server-side product catalogue must contain the following exact product:

```text
product_id       = sonkupik-live
name             = Sonkupik Live Full Version
amount_idr       = 249000
licence_type     = perpetual
computer_count   = 1
payment_method   = Midtrans QRIS
```

Required API behaviour:

1. `POST /v1/checkout` accepts `product_id`, `device_request_id`, customer name and customer email.
2. The response returns a protected order capability, trusted Midtrans checkout URL, `amount_idr: 249000`, and expiry time.
3. `POST /v1/orders/{id}/refresh` verifies Midtrans server-side and never trusts a client-provided payment result.
4. A paid order returns a signed activation generated by the existing private RSA key.
5. Private RSA and Midtrans server credentials must never be included in the desktop repository or executable.

The desktop implementation intentionally hard-fails a checkout response whose amount is not exactly Rp249.000. This prevents an outdated or incorrectly configured server product from opening a payment page with the wrong price.
