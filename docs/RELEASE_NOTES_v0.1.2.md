# SC220 Live v0.1.2

This patch release refines the production console without changing the proven routing model.

- Restores the detailed physical-mixer fader artwork while replacing its distracting grey side shape with a clean black backing.
- Rebuilds License & Activation as a balanced two-column workflow with clear purchase and offline activation paths.
- Preserves the intended Inter type hierarchy throughout the licence panel.
- Retains the compact premium console alignment, unified DSP control, improved Monitor Output spacing, and collision-free input controls.
- Includes the smart de-essing and pleasant mid-high protection already qualified by the compiled presence audit.

The Windows installer is built and audited locally. Only the binary allowlist is handed to `masarray/sc220-download`; its public workflow independently scans the repository and extracted installer payload for private ASK-P source, debug material, credentials, and key markers before publication.
