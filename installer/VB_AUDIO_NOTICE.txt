VB-CABLE is a separate product developed and owned by VB-Audio Software. It is included unchanged from the official VBCABLE_Driver_Pack45.zip package downloaded from:

https://shop.vb-audio.com/en/win-apps/11-vb-cable.html

The optional VB-CABLE task:

- requires Administrator permission;
- may show a Windows driver-security confirmation dialog;
- requires a Windows restart before the new CABLE Input and CABLE Output endpoints are fully available;
- installs only the standard VB-CABLE driver, not VB-CABLE A+B or C+D;
- can be deselected when VB-CABLE is already installed or when the user prefers to install it separately.
